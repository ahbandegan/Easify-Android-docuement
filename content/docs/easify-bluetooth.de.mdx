# easify-bluetooth

Das Modul `easify-bluetooth` bietet Werkzeuge für die Arbeit mit Bluetooth in Jetpack Compose. Dieses Modul macht die Verwaltung von Berechtigungen, das Ein- und Ausschalten von Bluetooth, das Scannen von Geräten und den Verbindungsaufbau sehr einfach.

## Installation

```kotlin
implementation("com.github.ahbandegan.Easify-Android:easify-bluetooth:2.1.0")
```

## Benutzerhandbuch

### 1. Bluetooth und Berechtigungen aktivieren (`rememberBluetoothLauncher`)
Um den Benutzer auf einfache Weise aufzufordern, Bluetooth einzuschalten und die erforderlichen Berechtigungen zu verwalten. Das Composable `rememberBluetoothLauncher` generiert eine an den Kontext gebundene Instanz.

```kotlin
import androidx.compose.foundation.layout.*
import androidx.compose.material3.Button
import androidx.compose.material3.Text
import androidx.compose.runtime.*
import androidx.compose.ui.Alignment
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import ir.amirhesambandegan.easify_bluetooth.rememberBluetoothLauncher

@Composable
fun BluetoothEnableScreen() {
    var bluetoothState by remember { mutableStateOf("Nicht aktiv") }

    val bluetoothLauncher = rememberBluetoothLauncher(
        onEnabled = { bluetoothState = "Bluetooth wurde erfolgreich aktiviert" },
        onDenied = { bluetoothState = "Bluetooth-Berechtigung verweigert" }
    )

    Column(
        modifier = Modifier.fillMaxSize(),
        horizontalAlignment = Alignment.CenterHorizontally,
        verticalArrangement = Arrangement.Center
    ) {
        Text(text = "Status: $bluetoothState")
        Spacer(modifier = Modifier.height(16.dp))
        Button(onClick = { bluetoothLauncher.launch() }) {
            Text("Bluetooth-Aktivierung anfordern")
        }
    }
}
```

### 2. Nach Bluetooth-Geräten scannen (`BluetoothScanner`)
Um nach Bluetooth-Geräten in der Nähe zu scannen, verwenden Sie die Klasse `BluetoothScanner`.

```kotlin
import androidx.compose.foundation.lazy.LazyColumn
import androidx.compose.foundation.lazy.items
import androidx.compose.material3.Button
import androidx.compose.material3.Text
import androidx.compose.runtime.*
import androidx.compose.ui.platform.LocalContext
import ir.amirhesambandegan.easify_bluetooth.BluetoothScanner
import ir.amirhesambandegan.easify_bluetooth.EasifyBluetoothDevice

@Composable
fun DeviceScannerScreen() {
    val context = LocalContext.current
    val scanner = remember { BluetoothScanner(context) }
    var scannedDevices by remember { mutableStateOf(listOf<EasifyBluetoothDevice>()) }
    var isScanning by remember { mutableStateOf(false) }

    Column {
        Button(onClick = {
            isScanning = true
            scanner.startScan { devices ->
                scannedDevices = devices
                isScanning = false
            }
        }) {
            Text(if (isScanning) "Scanne..." else "Nach Geräten scannen")
        }

        LazyColumn {
            items(scannedDevices) { device ->
                Text(text = "${device.name ?: "Unbekanntes Gerät"} - ${device.address}")
            }
        }
    }
}
```

## API-Referenz

### BluetoothAdvertiser
```kotlin
class BluetoothAdvertiser(context: Context) {
    val isAdvertising: StateFlow<Boolean>
    fun startAdvertising(serviceUuid: UUID, includeDeviceName: Boolean = true, onSuccess: () -> Unit = {}, onError: (errorCode: Int) -> Unit = {})
    fun stopAdvertising()
}
```
Verwaltet BLE Advertising (Beacon). `startAdvertising` benötigt eine UUID und optionale Parameter, um den Broadcast zu starten. `stopAdvertising` stoppt den Broadcast.

### BluetoothConnectionManager
```kotlin
enum class ConnectionState { DISCONNECTED, CONNECTING, CONNECTED, DISCONNECTING }

class BluetoothConnectionManager(private val context: Context) {
    val connectionState: StateFlow<ConnectionState>
    val discoveredServices: StateFlow<List<BluetoothGattService>>
    fun connect(device: EasifyBluetoothDevice, autoConnect: Boolean = false)
    fun disconnect()
    fun writeCharacteristic(serviceUuid: UUID, characteristicUuid: UUID, data: ByteArray): Boolean
}
```
Verwaltet GATT-Verbindungen. Die Eigenschaften `connectionState` und `discoveredServices` zeigen den Status und die erkannten Dienste. `connect` nimmt ein Gerät zum Verbinden entgegen und `disconnect` beendet die Verbindung. Die Methode `writeCharacteristic` sendet Daten an einen bestimmten Dienst und gibt einen Boolean zurück.

### BluetoothLauncher
```kotlin
class BluetoothLauncher(private val scanner: BluetoothScanner, private val observer: BluetoothObserver, private val onPermissionDenied: () -> Unit, private val coroutineScope: CoroutineScope) {
    val scannedDevices: Flow<List<EasifyBluetoothDevice>>
    val isEnabled: Flow<Boolean>
    val isScanning: StateFlow<Boolean>
    fun startScanning(serviceUuids: List<UUID>? = null, namePrefix: String? = null)
    fun stopScanning()
}

@Composable
fun rememberBluetoothLauncher(onPermissionDenied: () -> Unit = {}): BluetoothLauncher
```
Verwaltet Berechtigungen und Anforderungen zum Einschalten von Bluetooth. `rememberBluetoothLauncher` erstellt eine Instanz in Compose. `startScanning` benötigt optionale UUIDs und Präfixe, um den Scan zu filtern.

### BluetoothObserver
```kotlin
class BluetoothObserver(private val context: Context) {
    val isBluetoothEnabled: Flow<Boolean>
}
```
Beobachtet dynamisch den Bluetooth-Status. Bietet den `isBluetoothEnabled`-Flow, der basierend auf dem Status des Bluetooth-Adapters true oder false ausgibt.

### BluetoothScanner
```kotlin
class BluetoothScanner(context: Context) {
    val scannedDevices: Flow<List<EasifyBluetoothDevice>>
    fun startScan(serviceUuids: List<UUID>? = null, namePrefix: String? = null): Flow<Unit>
    fun clearDevices()
}
```
Scannt nach Geräten. `startScan` akzeptiert optionale Filter (UUID oder Präfix) und gibt einen Flow der erkannten Geräte zurück. `clearDevices` leert die Liste.

### BluetoothUtils
```kotlin
object BluetoothUtils {
    fun getRequiredPermissions(): List<String>
    fun Context.openBluetoothSettings()
}
```
Hilfsfunktionen. `getRequiredPermissions` gibt basierend auf der Android-Version eine Liste der erforderlichen Bluetooth-Berechtigungen zurück. `openBluetoothSettings` öffnet die Seite der System-Bluetooth-Einstellungen.

### EasifyBluetoothDevice
```kotlin
data class EasifyBluetoothDevice(
    val name: String?,
    val address: String,
    val rssi: Int,
    val device: BluetoothDevice
) {
    fun getEstimatedDistance(txPower: Int = -59): Double
    fun isBonded(): Boolean
    fun pair(): Boolean
    fun unpair(): Boolean
}
```
Eine Klasse, die ein erkanntes Gerät darstellt. `getEstimatedDistance` berechnet die geschätzte Entfernung mithilfe von `txPower` und gibt einen Double zurück. `pair` und `unpair` verwalten Pairing-Operationen und geben einen Boolean zurück.
