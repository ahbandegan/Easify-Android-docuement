# easify-storage

Dieses Modul bietet leistungsstarke Werkzeuge für die sichere und unsichere Speicherverwaltung sowie die Datenspeicherung. Von der Speicherung verschlüsselter Dateien bis hin zur Arbeit mit Jetpack DataStore auf einfachste Weise.

## Installation

```kotlin
implementation("com.github.ahbandegan.Easify-Android:easify-storage:2.1.0")
```

## Benutzerhandbuch

### Sichere Speicherung mit `DataStoreController`

Die Klasse `DataStoreController` bietet eine einfache Benutzeroberfläche zum Lesen, Schreiben und Beobachten von Einstellungen (Preferences) in Jetpack DataStore, die auch Verschlüsselung unterstützt.

```kotlin
import androidx.compose.foundation.layout.Column
import androidx.compose.material3.Button
import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.compose.runtime.collectAsState
import androidx.compose.runtime.getValue
import androidx.compose.runtime.remember
import androidx.compose.runtime.rememberCoroutineScope
import androidx.compose.ui.platform.LocalContext
import androidx.datastore.preferences.core.stringPreferencesKey
import ir.amirhesambandegan.easify_storage.DataStoreController
import kotlinx.coroutines.launch

@Composable
fun DataStoreExampleScreen() {
    val context = LocalContext.current
    val dataStoreController = remember { DataStoreController(context) }
    val coroutineScope = rememberCoroutineScope()
    
    // Einen Schlüssel definieren
    val tokenKey = stringPreferencesKey("user_token")
    
    // Daten reaktiv und sicher beobachten
    val token by dataStoreController.observeSecure(tokenKey).collectAsState(initial = null)

    Column {
        Text("Aktueller Token: ${token ?: "Nicht verfügbar"}")

        Button(onClick = {
            coroutineScope.launch {
                // Wert sicher und verschlüsselt speichern
                dataStoreController.saveSecure(tokenKey, "MySuperSecretToken123")
            }
        }) {
            Text("Sicheren Token speichern")
        }

        Button(onClick = {
            coroutineScope.launch {
                dataStoreController.remove(tokenKey)
            }
        }) {
            Text("Token löschen")
        }
    }
}
```

### Arbeiten mit verschlüsselten Dateien (`SecureFileStorage`)

Wenn Sie Dateien im Gerätespeicher ablegen und die Sicherheit ihres Inhalts gewährleisten müssen, können Sie `SecureFileStorage` verwenden. Dieses Tool nutzt Jetpack Security Crypto.

```kotlin
import androidx.compose.material3.Button
import androidx.compose.material3.Text
import androidx.compose.foundation.layout.Column
import androidx.compose.runtime.Composable
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.remember
import androidx.compose.ui.platform.LocalContext
import ir.amirhesambandegan.easify_storage.SecureFileStorage
import java.io.File

@Composable
fun SecureFileExample() {
    val context = LocalContext.current
    val secureFile = File(context.filesDir, "secret_data.txt")
    val content = remember { mutableStateOf("") }

    Column {
        Text("Dateiinhalt: ${content.value}")

        Button(onClick = {
            // Sicher und verschlüsselt in Datei schreiben
            SecureFileStorage.writeSecureString(context, secureFile, "Dies ist eine streng vertrauliche Nachricht!")
        }) {
            Text("In sichere Datei schreiben")
        }

        Button(onClick = {
            if (secureFile.exists()) {
                // Datei lesen und entschlüsseln
                content.value = SecureFileStorage.readSecureString(context, secureFile)
            }
        }) {
            Text("Aus sicherer Datei lesen")
        }
    }
}
```

```kotlin

```
Leert die internen und externen Cache-Verzeichnisse der App vollständig.

Ein Objekt, das für die Sicherung (Backup) und Extraktion lokaler App-Daten verantwortlich ist.

```kotlin
fun exportAppBackup(context: Context, outputFile: File): Boolean
```
