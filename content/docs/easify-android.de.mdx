# easify-android

Das Modul `easify-android` ist eine umfassende (Umbrella) Bibliothek, die alle Module von EasifyAndroid umfasst. Durch das Hinzufügen dieses Moduls haben Sie integrierten Zugriff auf alle Tools und Funktionen des EasifyAndroid-Ökosystems (einschließlich Kamera, Bluetooth, Biometrie und andere), ohne jedes Modul einzeln hinzufügen zu müssen.

## Installation

```kotlin
implementation("com.github.ahbandegan.Easify-Android:easify-android:2.1.0")
```

## Benutzerhandbuch

Nach der Installation dieses Moduls haben Sie Zugriff auf alle Funktionen des Ökosystems. Sie können beispielsweise alle Funktionen im Zusammenhang mit der Kamera, Bluetooth und der biometrischen Authentifizierung in Ihrem Projekt nutzen.
Um zu sehen, wie die einzelnen Tools verwendet werden, lesen Sie bitte die Dokumentation des jeweiligen Moduls:

- [Kamera](./easify-camera)
- [Bluetooth](./easify-bluetooth)
- [Biometrie](./easify-biometric)
- Und andere verfügbare Module im EasifyAndroid-Ökosystem.

## API-Referenz
Dieses Modul selbst hat keine direkten Klassen oder Funktionen und ist lediglich ein Wrapper für andere Module. Um auf die Dokumentation spezifischer Klassen zuzugreifen, lesen Sie bitte die Dokumentation der unabhängigen Module (wie Biometrie, Bluetooth, Kamera usw.).
