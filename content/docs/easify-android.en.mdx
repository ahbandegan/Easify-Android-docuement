# easify-android

The `easify-android` module is a comprehensive (Umbrella) library that encompasses all the modules of EasifyAndroid. By adding this module, you will have integrated access to all the tools and capabilities of the EasifyAndroid ecosystem (including camera, bluetooth, biometric, and others), without needing to add each module individually.

## Installation

```kotlin
implementation("com.github.ahbandegan.Easify-Android:easify-android:2.1.0")
```

## Usage Guide

With this module installed, you have access to all the features of the ecosystem. For example, you can use all capabilities related to the camera, bluetooth, and biometric authentication within your project.
To see how to use each specific tool, please refer to the documentation of that specific module:

- [Camera](./easify-camera)
- [Bluetooth](./easify-bluetooth)
- [Biometric](./easify-biometric)
- And other available modules in the EasifyAndroid ecosystem.

## API Reference
This module itself does not have a direct class or function, and is merely a wrapper for other modules. To access the documentation of specific classes, please refer to the documentation of the independent modules (like biometric, bluetooth, camera, etc.).
