# easify-validation

This module provides a comprehensive set of Regular Expressions (Regex) and validation tools to easily check the validity of user input data (such as emails, passwords, mobile numbers, and Iranian National IDs).

## Installation

```kotlin
implementation("com.github.ahbandegan.Easify-Android:easify-validation:2.1.0")
```

## Usage Guide

### Validating Inputs with `ValidationRegexes`

The `ValidationRegexes` class contains standard, ready-to-use patterns for validating various data types, including Iran-specific data formats.

**Example: Registration form and data validation**

```kotlin
import androidx.compose.foundation.layout.Column
import androidx.compose.foundation.layout.padding
import androidx.compose.material3.Button
import androidx.compose.material3.OutlinedTextField
import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.remember
import androidx.compose.runtime.setValue
import androidx.compose.ui.Modifier
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.unit.dp
import ir.amirhesambandegan.easify_validation.ValidationRegexes

@Composable
fun ValidationExampleScreen() {
    var email by remember { mutableStateOf("") }
    var mobile by remember { mutableStateOf("") }
    var nationalId by remember { mutableStateOf("") }
    
    var emailError by remember { mutableStateOf(false) }
    var mobileError by remember { mutableStateOf(false) }

    Column(modifier = Modifier.padding(16.dp)) {
        
        // Email Field
        OutlinedTextField(
            value = email,
            onValueChange = { email = it },
            label = { Text("Email") },
            isError = emailError
        )
        if (emailError) {
            Text("Invalid email format", color = Color.Red, modifier = Modifier.padding(bottom = 8.dp))
        }

        // Mobile Number Field (Iran)
        OutlinedTextField(
            value = mobile,
            onValueChange = { mobile = it },
            label = { Text("Mobile Number (e.g., 09123456789)") },
            isError = mobileError,
            modifier = Modifier.padding(top = 8.dp)
        )
        if (mobileError) {
            Text("Mobile number must be 11 digits and start with 09", color = Color.Red)
        }

        Button(
            onClick = {
                // Validate Email
                emailError = !ValidationRegexes.emailRegex.matches(email)
                
                // Validate Mobile
                mobileError = !ValidationRegexes.mobileRegex.matches(mobile)
                
                // Validate National ID
                val isNationalIdValid = ValidationRegexes.nationalIdRegex.matches(nationalId)
                
                if (!emailError && !mobileError) {
                    println("Data successfully verified!")
                }
            },
            modifier = Modifier.padding(top = 16.dp)
        ) {
            Text("Validate and Submit")
        }
    }
}
```

### List of Available Patterns (Regex)

The validation module supports the following patterns:
- `emailRegex`: Standard email address validation.
- `mobileRegex`: Iranian mobile number (e.g., `0912...`).
- `nationalIdRegex`: 10-digit National ID (structural check, no checksum calculation).
- `passwordStrongRegex`: Strong password (min 8 characters, includes uppercase, lowercase, numbers, and special characters).
- `postalCodeRegex`: 10-digit postal code.
- `landlineRegex`: Iranian landline phone number with area code.
- `urlRegex`: Standard internet addresses.
- `usernameRegex`: Username (3 to 20 characters including English letters, numbers, and underscores).
- `persianTextRegex`: Only Persian/Arabic letters and spaces.
- `englishTextRegex`: Only English letters and spaces.

## API Reference

### ValidationRegexes

A comprehensive Object containing widely-used Regular Expressions (Regex) for application-level data validation. These include validations for email, password, contact numbers, and Iran-specific formats.

#### Properties

```kotlin
val emailRegex: Regex
```
Used for validating standard email addresses.

```kotlin
val mobileRegex: Regex
```
Used for validating Iranian mobile numbers (must start with 09 and be exactly 11 digits).

```kotlin
val nationalIdRegex: Regex
```
Used for validating the Iranian National ID (checks for 10-digit structure only, without checksum calculation).

```kotlin
val passwordStrongRegex: Regex
```
Used for validating strong passwords (minimum 8 characters, containing English lowercase and uppercase letters, numbers, and a special character).

```kotlin
val postalCodeRegex: Regex
```
Used for validating Iranian postal codes (exactly 10 digits).

```kotlin
val landlineRegex: Regex
```
Used for validating Iranian landline numbers along with the area code (starting with 0 and totaling 11 digits).

```kotlin
val urlRegex: Regex
```
Used for validating standard internet addresses (URLs), with or without protocols and www.

```kotlin
val usernameRegex: Regex
```
Used for validating usernames (between 3 and 20 characters, consisting of letters, numbers, and underscores).

```kotlin
val persianTextRegex: Regex
```
Used to ensure the text only contains Persian/Arabic letters and spaces.

```kotlin
val englishTextRegex: Regex
```
Used to ensure the text only contains English letters and spaces.
