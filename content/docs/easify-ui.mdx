# easify-ui

این ماژول مجموعه‌ای از کامپوننت‌های رابط کاربری (UI) مدرن و منعطف برای Jetpack Compose است که به شما کمک می‌کند رابط‌های کاربری جذاب و کاربردی را در کمترین زمان بسازید.

## نصب (Installation)

```kotlin
implementation("com.github.ahbandegan.Easify-Android:easify-ui:2.1.0")
```

## راهنمای استفاده (Usage Guide)

### استفاده از `EasifyOtpInput` برای دریافت کد تایید

یکی از نیازهای رایج برنامه‌ها، دریافت کد تایید (OTP) است. `EasifyOtpInput` یک کامپوننت آماده و زیبا برای این منظور است که از انیمیشن‌های خطا (Shake) نیز پشتیبانی می‌کند.

```kotlin
import androidx.compose.foundation.layout.Column
import androidx.compose.foundation.layout.fillMaxWidth
import androidx.compose.foundation.layout.padding
import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.remember
import androidx.compose.runtime.setValue
import androidx.compose.ui.Modifier
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.unit.dp
import ir.amirhesambandegan.easify_ui.EasifyOtpInput

@Composable
fun OtpScreen() {
    var otpValue by remember { mutableStateOf("") }
    var hasError by remember { mutableStateOf(false) }

    Column(modifier = Modifier.padding(16.dp)) {
        Text("لطفاً کد تایید ۴ رقمی را وارد کنید:")
        
        EasifyOtpInput(
            value = otpValue,
            onValueChange = { newValue ->
                otpValue = newValue
                hasError = false // پاک کردن خطا هنگام تایپ مجدد
            },
            length = 4,
            isError = hasError,
            activeColor = Color.Blue,
            inactiveColor = Color.LightGray,
            modifier = Modifier.fillMaxWidth().padding(top = 16.dp),
            onComplete = { completedOtp ->
                // بررسی صحت کد وارد شده
                if (completedOtp != "1234") {
                    hasError = true
                }
            }
        )
        
        if (hasError) {
            Text(
                text = "کد وارد شده اشتباه است!",
                color = Color.Red,
                modifier = Modifier.padding(top = 8.dp)
            )
        }
    }
}
```

### استفاده از کنترل قطعه‌ای `EasifySegmentedControl`

این کامپوننت برای ایجاد یک منوی تب‌مانند زیبا و متحرک (شبیه به iOS Segmented Control) بسیار مناسب است.

```kotlin
import androidx.compose.foundation.layout.Column
import androidx.compose.foundation.layout.padding
import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableIntStateOf
import androidx.compose.runtime.remember
import androidx.compose.runtime.setValue
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import ir.amirhesambandegan.easify_ui.EasifySegmentedControl

@Composable
fun SegmentedControlExample() {
    val tabs = listOf("روزانه", "هفتگی", "ماهانه")
    var selectedTabIndex by remember { mutableIntStateOf(0) }

    Column(modifier = Modifier.padding(16.dp)) {
        EasifySegmentedControl(
            items = tabs,
            selectedIndex = selectedTabIndex,
            onItemSelected = { index ->
                selectedTabIndex = index
            }
        )

        Text(
            text = "گزینه انتخاب شده: ${tabs[selectedTabIndex]}",
            modifier = Modifier.padding(top = 24.dp)
        )
    }
}
```

### SuspendButton

```kotlin
enum class SuspendButtonType {
    FILLED,
    ELEVATED,
    TONAL,
    OUTLINED,
    TEXT
}
```
مجموعه‌ای از انواع استایل ظاهری برای کامپوننت دکمه.

```kotlin
@Composable
fun SuspendButton(
    onClick: suspend CoroutineScope.() -> Unit,
    modifier: Modifier = Modifier,
    type: SuspendButtonType = SuspendButtonType.FILLED,
    isLoading: Boolean = false,
    enabled: Boolean = true,
    loadingContent: @Composable () -> Unit = {
        CircularProgressIndicator(
            modifier = Modifier.size(20.dp),
            strokeWidth = 2.5.dp
        )
    },
    content: @Composable RowScope.() -> Unit
)
```
یک دکمه قابل سفارشی‌سازی با پشتیبانی از Coroutine‌های کاتلین و نمایش وضعیت بارگذاری. جلوگیری از کلیک‌های متوالی را به صورت خودکار مدیریت می‌کند.
